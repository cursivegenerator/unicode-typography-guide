# Unicode Typography Guide

This repository introduces Unicode typography and decorative text styles that can be used in compatible digital applications.

## What is Unicode Text?

Unicode is a character standard that allows computers to represent text from many writing systems, symbols, and special character sets.

Some decorative text styles use Unicode characters to create script-inspired, bold, or other visual effects.

## Try Different Text Styles

If you want to experiment with decorative lettering, [Cursive Generator](https://cursivegenerator.info/) provides copy-and-paste text styles for names, captions, and creative projects.

## Cursive Text

Script-inspired characters can be useful for short headings, display names, and personal messages.

Explore the [Cursive Text Generator](https://cursivegenerator.info/cursive-text-generator/) to preview different styles.

## Fancy Text

Decorative text can also include bold-looking characters, small letters, and other Unicode variations.

The [Fancy Text Generator](https://cursivegenerator.info/fancy-text-generator/) is another resource for exploring these styles.

## Compatibility

Unicode characters may appear differently depending on the fonts and applications available on a device. Always preview decorative text before using it in an important message or design.
